# Музыкальная библиотека

Десктопное приложение для ведения личной коллекции музыки с удобным поиском, фильтрацией и статистикой. Разработано на Python с использованием PyQt6 и SQLite.

---

## Основные возможности

- **Управление коллекцией:**
  - добавление трека через отдельное окно-диалог (`QDialog`) с полями: название, исполнитель, альбом, год, жанр и обложка;
  - просмотр подробной информации о треке по двойному клику на строке таблицы;
  - удаление выбранных треков с подтверждением через `QMessageBox`.

- **Обложки альбомов:** выбор изображения (`QFileDialog`) и предпросмотр в окне добавления, отображение обложки в окне информации о треке.

- **Фильтрация:** выпадающие списки по жанру и исполнителю; списки автоматически подгружаются из базы данных.

- **Экспорт в CSV:** сохранение плейлиста в файл `playlist.csv` (разделитель `;`, кодировка `utf-8-sig` для корректного открытия в Excel).

- **Валидация полей:**
  - обязательные: название трека, исполнитель, жанр — проверяются на заполненность;
  - год — проверяется на числовой формат;
  - опциональные: альбом, год — при незаполнении сохраняются как пустые значения и отображаются как «—».

- **Надёжное хранение:** все данные автоматически сохраняются в локальную базу данных SQLite (`music.db`).

---

## Структура проекта

```text

## Схема базы данных

- **groups** — справочник исполнителей (групп/артистов):
  - `id` — первичный ключ;
  - `name` — название исполнителя (уникальное);
  - `genres` — жанры исполнителя.

- **songs** — треки коллекции:
  - `id` — первичный ключ;
  - `group_id` — внешний ключ на `groups`;
  - `title` — название трека;
  - `album` — альбом;
  - `year` — год выпуска;
  - `genre` — жанр;
  - `cover_path` — путь к файлу обложки.

Связь: один исполнитель (`groups`) → много треков (`songs`).

## Установка и запуск

### Способ 1: Быстрый запуск (через готовый .exe)

1. Убедитесь, что исполняемый файл и файл базы данных (`music.db`) находятся в одной папке.
2. Дважды кликните по `main.exe` для запуска программы.

### Способ 2: Запуск из исходного кода (через Python)

1. Установите необходимые библиотеки:
   ```bash
   pip install PyQt6
   ```
2. Запустите приложение:
   ```bash
   python main.py
   ```

---

## Сборка в .exe

Приложение собирается в единый исполняемый файл через PyInstaller:

```bash
pyinstaller --onefile --windowed main.py
```

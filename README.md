# Название проекта: MusicLib

## Автор
Трухина Софья Андреевна

## Описание

Десктопное приложение для ведения личной коллекции музыки с поиском, фильтрацией и статистикой. Написано на Python с использованием PyQt6 и SQLite.

## Геймплей / Использование

- Добавляйте треки через окно-диалог: название, исполнитель, альбом, год, жанр, обложка
- Смотрите подробную информацию о треке по двойному клику
- Удаляйте выбранные треки с подтверждением
- Фильтруйте коллекцию по жанру и исполнителю
- Экспортируйте плейлист в CSV

## Особенности

- Обложки альбомов: выбор файла и предпросмотр
- Выпадающие списки фильтров подгружаются из базы
- Экспорт в `playlist.csv` (`;`, `utf-8-sig` — корректно открывается в Excel)
- Валидация: название, исполнитель, жанр — обязательны; год — число; альбом и год могут быть пустыми (отображаются как «—»)
- Все данные сохраняются в SQLite (`music.db`)

## Используемые технологии

- Python 3.12
- PyQt6 (интерфейс, диалоги, таблицы)
- SQLite (хранение данных)
- Модули Python: `csv` (экспорт), `os` (работа с путями к обложкам)
